# Shivansh Mani Tripathi — Portfolio

A static personal portfolio website. The site is intentionally separate from private project repositories.

## Publish with GitHub Pages (free)

1. Create a **public** GitHub repository named `Ansh826.github.io` (the username must match your GitHub account).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. After deployment, the site should be available at `https://ansh826.github.io`.

GitHub Pages on GitHub Free requires a public repository. Only publish this portfolio repository; do not upload private project source code, assets, design documents, credentials, or unreleased material.

## Before publishing

- Replace the LinkedIn placeholder URLs (`https://www.linkedin.com/`) with your actual profile URL.
- Confirm the email address and public contact preference.
- Review the project descriptions for accuracy.
- Add credential links only after checking each credential URL.
- Add screenshots only if you are comfortable making them public.

This is a static site; it does not contain a backend, login system, analytics, or contact form.
